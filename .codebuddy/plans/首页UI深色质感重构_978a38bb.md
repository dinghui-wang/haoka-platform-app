## 用户需求

重构号卡精选商城首页（`src/pages/index/index.vue`）的 UI 表现，将整体视觉风格从浅色明亮风改为深色质感风，保留所有业务逻辑不变。

## 产品概述

号卡精选商城是 uni-app 移动端应用，首页包含顶部品牌区、5G办理中心卡片、人气推荐、通知滚动条、运营商分类标签、搜索栏、商品列表和底部导航栏。本次重构仅涉及视觉层（template 结构 + SCSS 样式），不触碰 `<script setup>` 中的任何业务逻辑。

## 核心改造点

1. **整体色彩与布局**：页面背景从 `#F5F6FA` 改为深红/紫红渐变（`#8B1A32` / `#6A0DAD`）；所有卡片背景改为半透明深色 `rgba(20,10,30,0.6)` 并添加发光边框 `box-shadow`；卡片和按钮圆角统一加大至 `32rpx`（约16px）。
2. **顶部导航区**：Logo 区域改为红蓝渐变胶囊形状并左对齐；右上角新增星星图标和四角星图标，带 `@keyframes` 脉冲动画。
3. **标签筛选栏**：分类标签（精选/联通/移动/电信/广电）改为胶囊型样式；选中标签文字放大加粗、高亮色背景填充；未选中标签文字浅灰色。
4. **商品卡片**：从"左图右文"横向布局改为"上图下文"纵向布局；流量数字使用特大号加粗亮白/荧光绿居左对齐；价格放大字号亮色显示；卡片内边距增大；"免费领取"按钮改为高饱和度亮红/亮橙实心圆角胶囊按钮。
5. **底部TabBar**：毛玻璃效果 `backdrop-filter: blur(10px)` + 半透明黑色背景；图标放大；选中状态高亮色 + 上浮阴影。

## 技术栈

- 框架：uni-app (Vue3 `<script setup>` + Composition API)
- 预处理器：SCSS（已安装 `sass` 依赖）
- 单位：rpx（uni-app 响应式单位）
- 目标文件：`src/pages/index/index.vue`（单文件重构，script 不动）

## 实现方案

### 策略概述

仅重写 `index.vue` 的 `<template>` 和 `<style lang="scss" scoped>` 两部分，`<script setup>` 完全保留不动。通过 SCSS 变量统一管理深色主题色板，使用 `@keyframes` 实现脉冲动画，`backdrop-filter` 实现毛玻璃，将商品卡片从 `flex-direction: row` 改为 `column` 实现上图下文布局。

### 关键技术决策

1. **SCSS 变量集中管理**：在 `<style>` 顶部定义 `$bg-gradient-start`、`$bg-gradient-end`、`$card-bg`、`$card-glow`、`$accent-primary`、`$accent-secondary` 等变量，确保主题色一致性和可维护性。
2. **模板结构微调**：保持所有 `v-for`、`v-if`、`@click`、`:style`、`v-model` 等数据绑定和事件不变，仅调整 DOM 层级结构和 class 命名以适配新布局。新增的星星/四角星图标为纯装饰元素，不绑定业务数据。
3. **商品卡片纵向化**：将 `.product-card` 的 `flex-direction` 从默认 `row` 改为 `column`，图片宽度从 `200rpx` 改为 `100%`（自适应宽度），信息区移至图片下方。
4. **backdrop-filter 兼容性**：同时写 `-webkit-backdrop-filter` 和 `backdrop-filter` 确保多端兼容（H5 + 微信小程序）。
5. **脉冲动画**：使用 `@keyframes pulse` 控制图标 `transform: scale()` + `opacity` 实现脉冲效果，3s 循环。

### 性能与可靠性

- 动画仅用于小图标（星星/四角星），不影响滚动性能
- 商品卡片纵向布局后单屏可见数量减少，需确保 `scroll-view` 的 `@scrolltolower` 分页逻辑不受影响
- `backdrop-filter` 在低端设备可能降级，提供 `background: rgba(0,0,0,0.85)` 作为 fallback
- 不引入任何新依赖，不修改 `pages.json`、`App.vue` 或 API 层

## 实现注意事项

- **script 零改动**：`<script setup>`（1-287行）包含通知滚动、功能入口、推荐卡片、运营商主题、分类标签、商品列表、搜索、详情跳转、TabBar 导航等全部业务逻辑，重写 template/style 时必须保持所有变量引用和事件绑定不变
- **OPERATOR_THEME 保留**：运营商颜色配置（移动1/联通2/电信3/广电4）仍通过 `:style` 绑定到推荐卡片，深色主题下需调整这些颜色的对比度使其在深色背景上可读
- **rpx 单位一致性**：所有尺寸沿用 rpx（1px ≈ 2rpx），16px 圆角对应 32rpx
- **App.vue 全局背景**：`App.vue` 中 `page { background: #E8EAED }` 是 PC 端容器背景，本次不改 App.vue，但 `.page` 自身的 `background` 会覆盖该值
- **custom navigationStyle**：页面使用 `navigationStyle: "custom"`，无系统导航栏，顶部安全区由 `.header-bg` 的 `padding-top: 60rpx` 处理，保持不变

## 设计风格

采用深色质感（Dark Premium）风格，融合 Glassmorphism（毛玻璃半透明面板）与霓虹辉光元素，营造高级、神秘的购物氛围。

整体页面背景为深红至紫红的渐变（#8B1A32 → #6A0DAD），营造沉浸式暗色调氛围。所有内容卡片使用半透明深色背景（rgba(20,10,30,0.6)）配合微妙的彩色边框发光效果，形成层次分明的悬浮感。顶部品牌区域以红蓝渐变胶囊形状呈现 Logo，右上角点缀带脉冲动画的星星和四角星图标，增加活力感。

分类标签栏采用胶囊型设计，选中态以高饱和度亮橙色填充并放大加粗文字，未选中态为半透明浅灰色。商品卡片从横向布局改为纵向"上图下文"布局，流量数字以特大号荧光绿/亮白色加粗显示形成强烈视觉焦点，价格使用亮橙色放大呈现，右下角"免费领取"按钮为高饱和度亮红胶囊形实心按钮。

底部导航栏使用毛玻璃效果（backdrop-filter: blur(10px)）配半透明黑色背景，选中项图标和文字变为金色/红色高亮并带有上浮阴影。
